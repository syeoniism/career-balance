작성 도우미

작성 팁

  • • 구체적인 경험과 사례를 포함하세요
  • • 숫자와 데이터로 성과를 표현하세요
  • • 기업의 가치관과 연결 지으세요
  • • 진솔하고 솔직한 이야기를 담으세요

사용 방법

  1. 각 항목의 '자동 생성' 버튼 클릭
  2. 생성된 문구를 참고하여 내용 수정
  3. 본인의 실제 경험으로 구체화
  4. '작성 완료' 버튼을 눌러 저장

주의사항

자동 생성된 내용은 단순 예시입니다.
그대로 제출하지 마시고, 반드시 본인의 상황에 맞게 수정하여 사용해 주세요.
